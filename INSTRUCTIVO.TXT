Instructivo para correr la maquina virtual

Maquina Virtual desarrollada en JAVA y puede ejecutarse
en cualquier SO que disponga de JAVA 8 o superior.

Se necesita Java Runtime Environment (JRE) 8+ o superior
Verificar ejecutando en la consola java -version


Desde la consola (PowerShell), ubicada en la ruta donde esta guardado el proyecto ejecutar el siguiente comando:

vmx [ruta donde esta ubicado el archivo .vmx a probar en la VM] [-d] (en caso de querer ejecutar el disassembler)

Ejemplo de ejecucion

vmx C:\Users\NombreUsuario\Documentos\programa.vmx -d

Otra opcion 
tambien desde la ruta donde esta guardado el proyecto

java -cp bin mainVM [ruta donde esta el programa .vmx a ejecutar] -d

Otra opcion
tambien desde la ruta donde esta guardado el proyecto
desde la terminar de visual studio code ejecutar

.\vmx [ruta donde esta ubicado el archivo .vmx a probar en la VM] [-d] (en caso de querer ejecutar el disassembler)
